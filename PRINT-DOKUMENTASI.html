1. Pendahuluan

1.1 Tentang Aplikasi

Payroll System V2 adalah aplikasi penggajian karyawan lengkap yang dikembangkan dengan arsitektur One Page Coding. Semua logika backend, frontend, dan database dimuat dalam satu file PHP yang mudah di-deploy dan dikelola.

💡 Keunggulan One Page Coding:
• Deployment sederhana - hanya upload 1 file
• Maintenance mudah - semua dalam satu tempat
• Tidak perlu routing atau framework kompleks
• Cocok untuk UMKM hingga enterprise menengah

2. Instalasi

2.1 Instalasi Otomatis (Recommended)

Ikuti langkah-langkah berikut untuk instalasi dengan wizard:

Download & Extract

Download repository atau clone dengan git, kemudian extract ke folder web server.

git clone https://github.com/antono4/payrollphp.git
# Atau download ZIP dan extract

Buka Installer di Browser

Akses file installer melalui browser:

http://localhost/payroll-app/installer.php

Isi Konfigurasi Database

Masukkan informasi koneksi MySQL:

FieldDefaultDeskripsi
MySQL HostlocalhostHostname MySQL server
UsernamerootUsername MySQL
Password(kosong)Password MySQL
Database Namedb_payroll_v2Nama database baru

Klik "Install Sekarang"

Sistem akan otomatis:

  • Membuat database baru
  • Membuat semua tabel yang diperlukan
  • Menginsert sample data
  • Mengupdate konfigurasi di index.php

Akses Aplikasi

Setelah instalasi selesai, buka aplikasi utama:

http://localhost/payroll-app/index.php
✅ Tips Keamanan: Setelah instalasi berhasil, hapus file installer.php untuk mencegah akses tidak sah ke konfigurasi database.

2.2 Instalasi Manual

Jika lebih prefer instalasi manual:

Step 1: Buat Database

mysql -u root -p -e "CREATE DATABASE db_payroll_v2 
CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

Step 2: Import SQL

mysql -u root -p db_payroll_v2 < database.sql

Step 3: Edit Konfigurasi

Buka file index.php dan ubah bagian konfigurasi:

// Konfigurasi Database
define('DB_HOST', 'localhost');
define('DB_USER', 'root');
define('DB_PASS', 'password_anda');
define('DB_NAME', 'db_payroll_v2');

2.3 Konfigurasi Server

PHP Built-in Server (Development)

cd /path/to/payroll-app
php -S localhost:8000
# Buka: http://localhost:8000/index.php

Apache (XAMPP/WAMP)

# Copy folder ke htdocs (XAMPP) atau www (WAMP)
# Windows: C:\xampp\htdocs\payroll-app
# Linux: /opt/lampp/htdocs/payroll-app

Nginx

# Tambahkan virtual host di nginx.conf:
server {
    listen 80;
    server_name payroll.local;
    root /var/www/payroll-app;
    index index.php;
    
    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.0-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }
}

3.6 Proses Gaji

Kalkulasi otomatis dengan dua mode:

Proses Individual

  1. Pilih periode (bulan/tahun)
  2. Klik tombol "Proses" pada karyawan yang diinginkan
  3. Sistem akan menghitung dan menyimpan hasil

Proses Bulk (Semua)

  1. Pilih periode
  2. Klik tombol "Proses Semua"
  3. Konfirmasi aksi
  4. Sistem memproses seluruh karyawan aktif
⚠️ Catatan: Pastikan data kehadiran sudah diinput sebelum memproses payroll!

3.7 Laporan & Slip Gaji

Tiga jenis laporan tersedia:

A. Rekap Bulanan

Filter berdasarkan periode dan departemen, menampilkan:

  • Daftar karyawan dengan detail gaji

  • Ringkasan keseluruhan

B. Slip Gaji Individual

Detail lengkap per karyawan:

  • Data karyawan & kehadiran
  • Semua komponen tunjangan
  • Semua komponen potongan
  • Gaji bersih final

5. Kalkulasi Gaji

5.1 Komponen Tunjangan

KomponenFormulaContoh (Gaji Rp 10jt)
Tunjangan Jabatan Gaji Pokok × Persentase Rp 10.000.000 × 15% = Rp 1.500.000
JabatanPersentaseContoh (Rp 10jt)
Direksi35%Rp 3.500.000
General Manager30%Rp 3.000.000
Manager25%Rp 2.500.000
Assistant Manager20%Rp 2.000.000
Supervisor15%Rp 1.500.000
Senior Staff10%Rp 1.000.000
Staff8%Rp 800.000
Junior Staff5%Rp 500.000
Internship0%Rp 0
KomponenFormulaContoh
Tunjangan Transport 固定 per bulan Rp 500.000
Tunjangan Makan Rate × Hari Hadir Rp 30.000 × 24 = Rp 720.000
Tunjangan Kesehatan 固定 per bulan Rp 200.000
Tunjangan Masa Kerja 2% × Gaji × (Masa Kerja ÷ 12) Maks 10% dari gaji pokok
Bonus Hadir 5% × Gaji Pokok (jika hadir ≥ 24) Rp 10.000.000 × 5% = Rp 500.000
Bonus Lembur Rate/jam × Total Jam Rp 25.000 × 16 = Rp 400.000

5.2 Komponen Potongan

KomponenFormulaContoh
Potongan Alpa Rate × Hari Alpa Rp 100.000 × 2 = Rp 200.000
Potongan Izin 50% × Rate × (Izin - 2) lebih dari 2 hari izin
BPJS Kesehatan 1% × Gaji Pokok Rp 10.000.000 × 1% = Rp 100.000
BPJS Ketenagakerjaan 2% × Gaji Pokok Rp 10.000.000 × 2% = Rp 200.000
PPh 21 Progressive (lihat tabel) Berbeda per lapisan
Simpanan Wajib 1% × Gaji Pokok Rp 10.000.000 × 1% = Rp 100.000

Tarif PPh 21 Progressive (PTKP TK/0)

Lapisan PKP/TahunTarifContoh (PKP Rp 100jt)
0 - Rp 60.000.0005%Rp 60jt × 5% = Rp 3.000.000
Rp 60jt - Rp 250.000.00015%Rp 40jt × 15% = Rp 6.000.000
Rp 250jt - Rp 500.000.00025%-
> Rp 500.000.00030%-
📌 Catatan PPh 21:
• PTKP untuk TK/0 = Rp 54.000.000/tahun
• PKP = (Gaji + Tunjangan Jabatan) × 12 - PTKP
• PPh 21 bulanan = PPh 21 tahunan ÷ 12

5.3 Formula Perhitungan

📐 Gaji Bersih = Total Penghasilan - Total Potongan

TOTAL PENGHASILAN
= Gaji Pokok
+ Tunjangan Jabatan
+ Tunjangan Transport
+ Tunjangan Makan
+ Tunjangan Kesehatan
+ Tunjangan Masa Kerja
+ Bonus Hadir
+ Bonus Lembur

TOTAL POTONGAN
= Potongan Alpa
+ Potongan Izin
+ BPJS Kesehatan (1%)
+ BPJS Ketenagakerjaan (2%)
+ PPh 21 (Progressive)
+ Simpanan Wajib (1%)

GAJI BERSIH
= Total Penghasilan - Total Potongan

Contoh Perhitungan Lengkap

Data Karyawan:

  • Gaji Pokok: Rp 10.000.000
  • Jabatan: Supervisor (15%)
  • Hadir: 24 hari, Izin: 1 hari, Alpa: 0, Lembur: 8 jam

Perhitungan:

PENGHASILAN:
Gaji Pokok          = Rp 10.000.000
Tunj. Jabatan      = Rp  1.500.000  (10jt × 15%)
Tunj. Transport     = Rp    500.000
Tunj. Makan        = Rp    720.000  (30rb × 24)
Tunj. Kesehatan    = Rp    200.000
Tunj. Masa Kerja   = Rp          0  (< 12 bulan)
Bonus Hadir        = Rp    500.000  (5% × 10jt, hadir ≥ 24)
Bonus Lembur       = Rp    200.000  (25rb × 8)
                        ──────────────
TOTAL PENGHASILAN  = Rp 13.620.000

POTONGAN:
BPJS Kesehatan     = Rp    100.000  (1%)
BPJS TK            = Rp    200.000  (2%)
PPh 21             = Rp    150.000  (estimasi)
Simpanan Wajib     = Rp    100.000  (1%)
                        ──────────────
TOTAL POTONGAN     = Rp    550.000
